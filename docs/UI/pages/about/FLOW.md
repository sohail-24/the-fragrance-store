# Customer About Page User Flow

## Navigation Flow

```text
Storefront Visitor (Any Page)
       │
       ▼
Tap "About" in CustomerBottomNav (Fixed Bottom Bar)
       │
       ▼
Route Transition to /about
       │
       ▼
Render Hero Section ("Authentic Halal Cuisine")
       │
       ├──► Scroll to Halal Certification Standards
       │
       ├──► Explore 4 Quality Pillars (Meats, Produce, Spices, Freshness)
       │
       ├──► Interact with Halal FAQ Accordion (Expand/Collapse Answers)
       │
       └──► View Store Location, Hours, and Phone / Email
              │
              ├──► Tap Phone Number (tel: link)
              ├──► Tap Email (mailto: link)
              └──► Tap "Order Now" / "Explore Menu" (Returns to /categories or /)
```
